# Grand_Saint_Antoine
Metabarcoding analysis (PLA, CAF &amp; V4V5) of the Grand Saint Antoine

### Installing pipeline :

First, open your terminal. Then, run these two command lines :

    cd -place_in_your_local_computer
    git clone https://github.com/PLStenger/Grand_Saint_Antoine.git

### Update the pipeline in local by :

    git pull
